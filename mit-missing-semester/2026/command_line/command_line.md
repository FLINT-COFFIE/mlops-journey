# Commandline

## Arguments and Globs
1. using the flag -- before creating a file lets you use or include special characters in the naming.
eg touch -- -myfile.

2. using ls
ls -lsht --color=always

ls to list the files and -lsht to list all, size and time.

3. Process substitution
printenv shows environment variables that are passed down to subprocesses

export unveils these builtin processes so subprocesses jave access to it.
